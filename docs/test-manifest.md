# Test manifest

This manifest maps review invariants to executable tests and release scripts.

| Case | Invariant                                                                                              | Test or gate                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| R1   | Delete versus backfill leaves no orphan                                                                | `lifecycle.race.test.ts` — `R1 delete versus backfill leaves no orphan`, 20 runs                                                              |
| R2   | Updates before and after a backfill cursor converge                                                    | `lifecycle.race.test.ts` — `R2 updates before and after the backfill cursor converge`, 20 runs                                                |
| R3   | Insert around the backfill cursor is present                                                           | `lifecycle.race.test.ts` — `R3 insert around the backfill cursor is indexed`, 20 runs                                                         |
| R4   | Mid-build maintenance supersedes the old generation                                                    | `lifecycle.race.test.ts` — `R4 repair mid-backfill supersedes the old generation`, 20 runs                                                    |
| R5   | Create/delete/create leaves no dead-index entries                                                      | `lifecycle.race.test.ts` — `R5 create delete create leaves no entries under the dead index`, 20 runs                                          |
| R6   | Table deletion during backfill fully purges                                                            | `lifecycle.race.test.ts` — `R6 table deletion during backfill purges all residue`, 20 runs                                                    |
| R7   | Concurrent unique writes admit one logical value                                                       | `lifecycle.race.test.ts` — `R7 concurrent unique inserts admit one logical value`, 20 runs                                                    |
| R8   | Concurrent idempotent batches return identical IDs; mismatch fails                                     | `lifecycle.race.test.ts` — `R8 concurrent idempotent batches return the same IDs`, 20 runs                                                    |
| R9   | Concurrent expected-revision patches have one winner                                                   | `lifecycle.race.test.ts` — `R9 concurrent expectedRev patches have one winner`, 20 runs                                                       |
| O1   | Oracle recomputes the complete sidecar set                                                             | `assertOracle` after every applicable race in `lifecycle.race.test.ts`                                                                        |
| O2   | Read-only verification detects a skipped writer path                                                   | `runtimeTables.test.ts` — `read-only verification detects a deliberately skipped writer update`                                               |
| O3   | Verification never repairs the injected mismatch                                                       | Same test asserts failed verification while the ready serving state remains ready                                                             |
| C1   | Ascending/descending pagination has exact reverse order and no gaps across an intervening write        | `runtimeTables.test.ts` — `builds and pages a composite range index in exact order`                                                           |
| C2   | Large unfiltered traversal uses structural pagination                                                  | `runtimeTables.test.ts` — `paginates an unfiltered table beyond the scan threshold`                                                           |
| C3   | Schema revision and index deletion invalidate old cursors                                              | `runtimeTables.test.ts` — `invalidates cursors after a result-shaping schema change`                                                          |
| C4   | End cursors work; oversized, malformed, and tampered cursors fail                                      | Planner cursor cases in `runtimeTables.test.ts`; 8 KiB enforcement in `planner.ts`                                                            |
| S1   | Foreign-scope IDs fail closed                                                                          | `runtimeTables.test.ts` — `keeps the public isolation matrix synchronized with every export`; host rollback test in `example.test.ts`         |
| S2   | Newly exported public operations require isolation and dispatcher coverage                             | The hard-coded public export list in `runtimeTables.test.ts` and closed operation schema in `agent/index.test.ts` fail on uncovered additions |
| L1   | NaN, infinity, zero, negative, and fractional budgets fail                                             | `runtimeTables.test.ts` — `rejects invalid pagination budget` parameter matrix                                                                |
| L2   | Record and entry size accounting uses Convex sizes with rollback                                       | `runtimeTables.test.ts` — record and generated-index limit cases; `validation.ts` and `data.ts`                                               |
| L3   | Indexed strings use NFC and a 1 KiB cap                                                                | `normalization.test.ts` and record/index build tests                                                                                          |
| L4   | Field/index counts, constraint applicability, reference targets, and unique-null semantics are bounded | Limit, reference, and nullable-unique cases in `runtimeTables.test.ts`                                                                        |
| Q1   | Multi-range queries return no impossible suggestion; every emitted suggestion works                    | `runtimeTables.test.ts` — multi-range rejection and `makes every emitted index suggestion plannable`                                          |
| Q2   | Large unfiltered tables remain listable                                                                | `runtimeTables.test.ts` — `paginates an unfiltered table beyond the scan threshold`                                                           |
| A1   | Malformed, prototype, wrong-type, extra, and oversized agent JSON fails                                | `agent/index.test.ts` — agent dispatcher suite                                                                                                |
| D1   | Packed tarball mounts in a clean Vite and Convex consumer                                              | `scripts/consumer-smoke.mjs`; CI `test:consumer`                                                                                              |
| D2   | Second codegen has zero generated drift                                                                | `scripts/consumer-smoke.mjs` directory digest assertion                                                                                       |
| D3   | Packed consumer executes a mutation and query                                                          | `scripts/consumer-smoke.mjs`, output fields `mutation` and `queryCount`                                                                       |
| D4   | One client subscription observes another client write                                                  | `scripts/consumer-smoke.mjs`, output field `reactiveCount`                                                                                    |
| D5   | 100k live-write, two-index, oracle, full traversal benchmark                                           | `scripts/live-scale.mjs`; nightly/manual `test:scale`                                                                                         |

The normal CI gate runs format, lint, typecheck, unit/race tests, coverage,
build, packed consumer, codegen freshness, mutation/query, and reactivity. The
nightly/manual workflow adds the 100k deployment gate.
